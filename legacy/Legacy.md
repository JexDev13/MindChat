# Legacy del Proyecto MindChat

En esta carpeta encontrarás el código y recursos correspondientes a versiones anteriores o componentes heredados del proyecto MindChat. El propósito de este espacio es conservar funcionalidades, referencias y documentación de implementaciones previas que pueden ser útiles para mantenimiento, migraciones o consulta histórica.

**¿Qué puedes esperar encontrar aquí?**

- Código fuente de versiones anteriores del sistema.
- Documentación y notas sobre decisiones técnicas pasadas.
- Proyectos, soluciones y archivos que ya no forman parte del desarrollo principal pero pueden ser relevantes.
- Referencias para migraciones o integraciones con el sistema actual.

Esta carpeta es especialmente útil para desarrolladores que necesiten entender la evolución del proyecto o recuperar funcionalidades antiguas.
